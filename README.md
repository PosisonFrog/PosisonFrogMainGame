# JO:E / PoisonMainGame
청강문화산업대학교 학기작으로 제작한 Unreal Engine 기반 3D 액션 게임 프로젝트입니다.<br/>
해머를 사용하는 플레이어 캐릭터를 중심으로 기본 공격, 대시, 회전 공격, 띄우기-내려찍기 커맨드 스킬, 콤보 랭크, 궁극기, 스테이지 진행, 튜토리얼, 보스전 시스템을 구현했습니다.

- 엔진: Unreal Engine 5.3
- 플랫폼: Windows / Desktop 

## Game Features
- 해머 기반 3D 근접 액션 전투
- 기본 공격 콤보와 피격 반응 시스템
- 대시 입력 버퍼, 쿨타임, 이동 속도 버프
- 홀드형 회전 공격 스킬과 피니셔 연출
- 띄우기 후 제한 시간 안에 재입력해 내려찍는 커맨드 스킬
- 콤보 스택과 D~S 랭크 기반 궁극기 시스템
- 이동 속도, 데미지, 체력, 방어 보정이 적용되는 궁극기 버프
- 일반 적 AI, 추적/공격/복귀 상태 머신, 군집 추적 보정
- 보스 페이즈와 패턴 관리 시스템
- 스테이지 트리거, 배리어, 체크포인트, 튜토리얼 흐름 제어
- UMG 기반 HUD, 메인 메뉴, 옵션, 컷신 위젯
- Niagara VFX, Sound Data Asset, 사운드 매니저 서브시스템
